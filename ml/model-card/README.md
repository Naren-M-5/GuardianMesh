# Guardian temporal risk model card

Status: baseline rules only; no trained model is shipped yet.

Intended use: flag unusual Ring event patterns for owner review. Not intended for identity recognition, crime prediction, medical inference, or autonomous emergency response.

Planned evaluation: scenario-level precision/recall, false positives per normal day, alert latency, calibration, and subgroup/lighting-condition analysis where labels permit. The late-resident case must demonstrate contextual risk reduction before any claim of adaptive intelligence.
