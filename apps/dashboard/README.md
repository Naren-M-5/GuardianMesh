# Dashboard contract

Planned Next.js views:

- `/`: space status, current risk, routine summary, Ask Guardian entry
- `/live`: live canonical events
- `/incidents`: incident history
- `/incidents/[id]`: timeline, evidence, explanation, resolution
- `/activity`: activity timeline
- `/routines`: behavioral profile
- `/guardian`: evidence-grounded questions
- `/privacy`: privacy controls
- `/settings`: devices, zones, and notification preferences

The UI must distinguish observed facts, inferred observations, risk assessments, and agent-generated prose. Never show identity claims for unknown people.
